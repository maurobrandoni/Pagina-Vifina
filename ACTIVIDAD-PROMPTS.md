# Actividad: ¿cómo le pedimos las cosas a la IA?

## Qué vamos a hacer

Vamos a pedirle a una IA (ChatGPT o Gemini) **la misma página web** de tres formas distintas. Después comparamos los resultados y vemos qué cambia.

La idea es que descubran por sí mismas una cosa: **cuanto mejor le explicás algo a la IA, mejor te sale lo que te devuelve.**

Tiempo: unos 45 minutos. Pueden hacerlo de a dos.

## Antes de empezar

- Abran ChatGPT o Gemini en el navegador.
- Abran **un chat nuevo para cada prompt**. Si no, la IA se acuerda de lo anterior y no es una prueba justa.
- **No escriban datos personales** en el chat: ni apellidos, ni el nombre del colegio, ni teléfonos, ni mails.
- La IA se equivoca, y a veces **inventa cosas con mucha seguridad**. Siempre revisan ustedes.

## Paso 1: probar los tres prompts

Un *prompt* es lo que le escribimos a la IA. Copien y peguen cada uno en un chat nuevo.

### Prompt 1: corto

```
Haceme una página web de ciberseguridad.
```

### Prompt 2: con detalles

```
Haceme una página web para una empresa de ciberseguridad que se llama Vifina.
Tiene que explicar los servicios que ofrece (protección de datos, seguridad contra hackers y monitoreo mensual), usar colores azul y verde, y verse bien en el celular.
Dame el código en un solo archivo HTML.
```

### Prompt 3: con orden

```
Actuá como una diseñadora web que les enseña a estudiantes de secundaria.

Quiero una página web de una empresa ficticia de ciberseguridad que se llama Vifina.

Tiene que tener estas secciones, en este orden:
1. Portada con un título grande y un botón de contacto.
2. Sobre nosotras.
3. Servicios, en 5 tarjetas: seguridad frente a hackers, protección de datos, monitoreo mensual, sistemas de protección actualizados y explicación sencilla para clientes.
4. Cómo cuidamos tu empresa, en 4 pasos.
5. Contacto.

Estilo: azul oscuro y verde brillante, letra grande y fácil de leer, que se vea bien en el celular.

Formato: un solo archivo index.html con el CSS adentro. Sin librerías externas. Todo el texto en español.

Reglas: no inventes clientes, empresas famosas, teléfonos ni direcciones reales.

Al final, explicame en 5 líneas qué hace cada parte del código.
```

## Paso 2: guardar y abrir cada página

1. Copien **solo el código** que devolvió la IA (empieza con `<!DOCTYPE html>` y termina con `</html>`).
2. Abran el Bloc de notas (o cualquier editor de texto) y peguen el código.
3. Guarden el archivo con **Guardar como**, eligiendo el tipo **Todos los archivos**, con el nombre `prompt1.html`. Hagan lo mismo con `prompt2.html` y `prompt3.html`.
4. Hagan doble clic en cada archivo. Se abre en el navegador.

Si la IA no les dio código, escriban: *"Dame todo el código en un solo archivo HTML"*.

## Paso 3: comparar

Completen esta tabla con ✅ o ❌. En la última fila, pónganle una nota del 1 al 10.

| Pregunta | Prompt 1 | Prompt 2 | Prompt 3 |

## Paso 4: revisar lo que dijo la IA

Lean el texto de cada página con atención y contesten:

- ¿Hay alguna frase que afirme algo que no podemos comprobar? Por ejemplo, "más de 500 clientes" o "la empresa favorita de Google".
- ¿Hay datos de contacto? ¿Son reales o inventados?
- ¿Hay algún error de ortografía o una palabra rara?

Si encuentran algo inventado, **no se queda**: lo borran o le piden a la IA que lo saque.

## Paso 5: mejorar el prompt

Elijan el prompt que peor les salió y escriban esto en un chat nuevo:

```
Este es un prompt que le escribí a una IA para que haga una página web:

"(pegá acá el prompt)"

Decime qué información le faltaba para que el resultado salga mejor, y reescribilo.
```

Después prueben el prompt mejorado y miren si la página cambió.

## Para cerrar

Contesten en grupo, con sus palabras:

1. ¿Qué diferencia hubo entre el Prompt 1 y el Prompt 3?
2. ¿Qué cosas tenía el Prompt 3 que los otros no?
3. ¿La IA acertó en todo? ¿Qué tuvieron que corregir ustedes?
4. Si tuvieran que explicarle a una amiga cómo pedirle algo a la IA, ¿qué tres consejos le darían?

## Guía rápida para escribir un buen prompt

- **Decile quién tiene que ser:** "Actuá como una diseñadora web".
- **Contale para qué es:** una página de una empresa ficticia de ciberseguridad.
- **Decile qué querés, paso por paso:** las secciones, en orden.
- **Pedile un formato:** un solo archivo HTML, todo en español.
- **Ponele reglas:** "no inventes datos".
- **Revisá siempre** lo que te devuelve.
